隐私政策

适用于 ytbatch（个人 YouTube 批量上传工具）· 最后更新：2026 年 11 月 16 日

ytbatch 是一个由个人开发者自用、运行在本地电脑或自有服务器上的命令行程序。本政策说明该程序如何处理数据。

1. 我们收集哪些数据

ytbatch 不收集任何个人数据，也没有服务器端数据库。程序运行过程中产生的数据全部保存在运行它的那台机器上：

  • token.json：Google OAuth 授权令牌，用于代表你本人调用 YouTube Data API
  • state/ledger.json：已上传视频的本地记录（文件名、视频 ID、发布时间等）
  • 本地日志文件：运行过程中的诊断信息

2. 数据如何被使用

授权令牌仅用于调用 YouTube Data API v3，完成以下操作：

  • 上传你本人选择的视频文件到你本人的频道
  • 设置视频的标题、描述、标签、分类、可见性与定时发布时间
  • 设置视频封面、把视频加入你本人的播放列表

程序不会读取你的邮件、联系人、日历、云端硬盘或任何与 YouTube 频道无关的数据。

3. 数据共享

不共享、不出售、不转让。除 Google 官方 API 端点（googleapis.com）外，程序不会向任何第三方服务器发送数据。

4. 数据保留与删除

  • 所有本地文件由使用者自行保管和删除。
  • 删除 token.json 即终止本程序的访问权限。
  • 你也可以随时在 Google 账号权限页 撤销对本应用的授权。

5. 使用的 Google 权限范围

本程序仅请求以下 OAuth 范围：

  • https://www.googleapis.com/auth/youtube —— 管理你本人 YouTube 账号的内容（上传、编辑视频信息、管理播放列表）

该范围用于 YouTube API 服务条款 所允许的用途。

6. 儿童隐私

本程序不面向儿童，也不收集任何人的个人信息。

7. 安全

授权令牌以文件形式保存在本机，建议仅限本人账户可读。程序不通过互联网传输令牌。

8. 政策变更

如本政策发生变更，更新后的版本将发布在本页面。
