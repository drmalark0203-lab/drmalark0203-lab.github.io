ytbatch

个人自用的 YouTube 批量上传工具（本地命令行程序）

ytbatch 是一个运行在开发者本人电脑或自有服务器上的命令行程序，用于把本地视频文件批量上传到本人拥有的 YouTube 频道。

它做什么

  • 读取本地视频文件及其元数据（标题、描述、标签、封面）
  • 通过 YouTube Data API v3 上传到本人频道，并设置可见性与定时发布
  • 在本地记录已上传视频，避免重复上传

它不做什么

  • 不对外提供服务，没有注册功能，没有其他用户
  • 不收集、不分析、不转售任何用户数据
  • 不读取你 Google 账号中除 YouTube 频道操作权限以外的任何内容

数据与隐私

本程序仅在本地保存 OAuth 令牌和上传记录，具体说明见 隐私政策。
